## IPLC 云服务器到底是什么，和普通 VPS 差在哪

先把概念捋直。IPLC 指国际私有租用线路，本质是跨境的点对点专用通道：流量不走公网，不经过公共国际出口，所以不会遇到公网 IP 被目标平台拉黑、线路高峰期拥堵丢包这类问题。IEPL 是它的"以太网版"，对用户来说差异不大；MKCloud 商店里两者都按"专线云服务器"交付，选线主要看方向和延迟，不用纠结名字。

它和普通 VPS 的区别，用 MKCloud 的交付模型讲最清楚。每台专线 VPS 有两个 IP：

- **入口 IP**：你在国内用它远程连接服务器，走 RDP 或 SSH 登录。
- **出口 IP**：VPS 里的业务流量从这个 IP 发往境外目标，这个 IP 承载在专线对端，干净且稳定。

关键在于，出口只出不进。外部用户没法主动连入你的出口 IP，所以它不适合做对外网站、支付回调这类需要被访问的业务——它的定位是你自己人在国内操作、业务程序在服务器里向外跑的场景，比如店铺运营、API 调用、远程开发。

三条线在 MKCloud 商店里是这么分的：

| 类型 | 交付形式 | 接入条件 |
| --- | --- | --- |
| IPLC / IEPL 专线 | 整机交付，入口可选电信或 BGP | 绑定一个省份连入，可修改 |
| IXP 上云互联专线 | 云厂优化入口 + 境外出口 | 需要已有一台国内云厂机器做前置 |
| 独享带宽款 | 带宽独享、流量不限 | 同上两种入口都有对应款 |

还有一个容易被忽略的点：专线产品的带宽写着"峰值"，属于共享带宽，不保证持续跑满；流量按上行加下行双向统计，多数流量计费套餐超量后会直接停机，而不是降速。这两条直接决定了"带宽大"不等于"适合你"，后面细说。

## 怎么选：按业务方向和手头条件对号入座

选线只看两个变量：你的业务在哪个方向，你的机器在什么网络上。

**香港方向**是跨境电商最集中的选择，广港 IEPL 和沪港 IPLC 二选一。人在华南、公司或居家网络在广州周边，广港 IEPL 的 1~2ms 端内延迟几乎是本地体验；在上海或华东，沪港 IPLC 的 21ms 也完全够用。这两条线的 1TB 档分别是 358 元和 288 元，日常店铺运营、ERP 同步都在合理预算内。

**日本方向**做 TikTok、Shopee、日淘类业务，选沪日 IPLC 或沪日 IX。25~28ms 的端内延迟对操作响应没有可感知影响，重点是出口 IP 的地区属性匹配平台风控预期。

**美国方向**覆盖 eBay、Shopify 后台、美区开发测试这些场景。沪美 IPLC 124~134ms 的延迟做 SSH 和后台操作没问题，别拿它追求游戏级体验。1TB 档 428 元是试水美国线路最低成本的正规选项。

**预算敏感且已有云厂机器**的，直接看 IXP 线。158 元的沪港 2TB 档把入门价压到了别人普通 VPS 的水平，条件只是前置那台云厂机器本身。注意购买页会标注各云厂入口的可用状态，个别云厂区域可能暂时不通，下单前看一眼当前说明。

**持续大流量传输**的再考虑独享款。判断方法很简单：算一下你的月流量，如果按流量计费档位买要跳到 6TB 以上，或者业务对速率稳定性有硬要求（比如定时备份窗口固定、上传不能断），独享款包月反而干净。

## 购买前必读的限制

这几条都是购买页的原文要求，逐条列出来，避免买了再后悔：

1. **实名和白名单**：需要中国身份信息实名；直连产品只允许所绑定省份的 IP 连入，白名单机制明确用于禁止机场、回国等违规用途，违规会被清退且不退款。
2. **出口不能被连入**：想做对外网站、需要接收回调的支付接口，这套架构不适用。
3. **流量双向统计**：上下行加起来计算，超量后多数流量款直接停机，可自助购买流量重置或工单补差价升级。估算月流量时按双向算。
4. **退款条件苛刻**：只有质量问题可退，且要提交具体延迟、速度数据作为证据；开通后不支持更换地域。不存在"试用不满意随便退"。
5. **无默认 SLA**：标准产品不带服务等级保证，有高可用需求的要先通过工单询价确认，别把默认套餐当成已含 SLA。

## 常见问题

**IPLC 云服务器为什么比普通 VPS 贵这么多？**

差价全在线路上。普通 VPS 的成本是一台共享宿主机加一条公网线路，IPLC 的成本是跨境专用通道，两端还要各分配一个独立 IP。288 元的沪港 1TB 档和 28 元的普通 VPS 不是同一类商品，前者买的是 IP 稳定性和链路质量，后者买的是便宜。

**共享峰值的带宽能跑满吗？**

峰值不等于保证值，短时间冲高没问题，持续满速要看同时段线路占用。官方建议用 iperf3 做吞吐测试（需要对端配合，且持续满载很费流量）。如果你的业务是持续型传输，直接看独享款。

**端内延迟 21ms 是指我访问的整体延迟吗？**

不是。端内延迟只覆盖专线内部段（入口到出口），你的整体延迟还要加上本地到入口、出口到目标网站的段。第三方测评常引用"广港低至 3ms"指的是端内数字，自己评估时要把全程链路分开看。

**一个人能管理多台专线 VPS 吗？**

可以，每台机器独立分配入口和出口 IP，彼此不共享。多店运营按店铺隔离机器是常见做法，具体怎么分配看业务需要。

**该月付还是年付？**

按已确认的沪港 1TB 档，年付没有折扣，那就先月付跑一个月验证业务场景，确认 IP 和线路质量符合预期后再考虑长周期，反正升降级都要走工单，长周期反而锁死灵活性。
